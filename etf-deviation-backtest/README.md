# ETF / 指数偏离率回测系统

本地运行的可视化回测工具，用「价格相对均线的偏离率」触发买卖，统计策略表现。
**支持电脑、Android、iOS 浏览器访问**，也可「添加到主屏幕」当独立 App 用。

## 快速开始

双击 `启动.bat`，或手动执行：

```bash
python server.py
```

启动后终端会显示两个地址：

```
本机访问：   http://127.0.0.1:8770
局域网访问： http://192.168.x.x:8770   ← 手机连同一 Wi-Fi 用这个
```

手机 / 平板连**同一个 Wi-Fi**，用第二个地址即可打开。桌面端侧边栏底部有二维码，扫一下直接进手机。

**手机添加到主屏幕**（像原生 App 一样全屏使用）：

- **iOS**：Safari 打开 → 分享 → 「添加到主屏幕」
- **Android**：Chrome 打开 → 菜单 → 「添加到主屏幕 / 安装应用」

核心功能零第三方依赖，Python 3.8+ 标准库即可运行。二维码功能需额外装一个轻量库（见下）。

## 策略逻辑

以收盘价计算偏离率：

```
deviation = (close - MA) / MA × 100%
```

- `deviation ≤ 买入偏离率`（默认 **-4**）→ 买入信号
- `deviation ≥ 卖出偏离率`（默认 **+5**）→ 卖出信号

> 买入偏离率是**负数**，卖出是**正数**。为兼容旧写法，若买入传入正数会自动取负，卖出传入负数会取绝对值。

**成交假设**：信号在收盘后产生，次日**开盘价**成交（避免未来函数）。A 股 100 股整数倍，含双边佣金与最低 5 元佣金。

## 可配置参数

| 参数 | 说明 |
|------|------|
| 标的 | 17 个 ETF / 指数，含宽基、行业、商品、海外 |
| 回测区间 | 起始日 / 截止日，另有近1年/3年/5年/全部快捷键（默认近1年） |
| 均线周期 | 默认 **20** 日，5–250 可调（数字框可填至 500） |
| 买入偏离率 | 默认 **-4%**，偏离率低于该值触发买入（负数） |
| 卖出偏离率 | 默认 **+5%**，偏离率高于该值触发卖出（正数） |
| 初始资金 | 默认 10 万 |
| 佣金费率 | 默认 0.05% 双边 |
| 仓位模式 | 满仓进出 / 半仓进出 |

## 输出指标

**当前偏离率**、**区间最大/最小偏离率**（含发生日期）、**策略收益率**、基准（买入持有）收益率、超额收益、年化、最大回撤、夏普比率、年化波动、交易次数、胜率、盈亏比、平均盈亏、持仓占比、累计手续费、期末净值，外加逐笔成交记录（区分信号日与成交日）。

三张联动图表（鼠标/手指悬停时十字光标同步）：

1. **偏离率走势** — 含买入区 / 卖出区色带与阈值线
2. **价格与均线** — 标注买卖点
3. **收益对比** — 策略净值 vs 基准净值

## 数据源

- 主源：腾讯财经 `ifzq.gtimg.cn`，**前复权**，分页拉取，可回溯至 2013 年
- 备源：新浪财经（不复权，仅在主源失败时兜底）

复权口径会显著影响偏离率计算，因此优先使用前复权数据。

> 注意：本地 Python 访问东财接口会被 TLS 指纹拦截（curl 可通），故改用腾讯源。

## 多端适配说明

| 项目 | 做法 |
|------|------|
| 监听地址 | 绑定 `0.0.0.0` 而非 `127.0.0.1`，同网段设备才连得上 |
| 端口 | 读环境变量 `PORT`，默认 8770（便于部署到云主机） |
| 传输压缩 | 响应自动 gzip，行情接口从 276KB 压到 81KB（省 70%），手机流量友好 |
| 移动端布局 | ≤1024px 时参数面板变抽屉、KPI 两列、指标两列、表格横向滚动 |
| 触摸优化 | 所有可点区域 ≥44px；输入框 16px 字号（防 iOS 聚焦自动放大） |
| 手势 | 图表横向拖动查数据、纵向滑动正常翻页，不互相打架 |
| 安全区 | 全面屏刘海 / 手势条通过 `env(safe-area-inset-*)` 避让 |
| PWA | 带 manifest + Service Worker，可添加到主屏全屏运行，断网仍能打开界面 |
| 二维码 | 桌面端展示，手机扫码直连 |

## 安装二维码功能（可选）

```bash
pip install segno
```

不装也不影响使用，只是侧边栏不显示二维码（仍会显示文字地址）。

## 部署到云服务器

服务已支持 `PORT` 环境变量与 `0.0.0.0` 绑定，可直接部署：

```bash
PORT=80 python server.py          # Linux
$env:PORT=80; python server.py    # Windows PowerShell
```

部署后手机通过公网 IP 即可访问。注意：公网暴露时建议自行加一层 HTTPS 反向代理。

## API

```bash
# POST 回测
curl -X POST http://127.0.0.1:8770/api/backtest \
  -H "Content-Type: application/json" \
  -d '{"code":"510500","ma_period":60,"buy_dev":10,"sell_dev":10}'

# GET 回测
curl "http://127.0.0.1:8770/api/backtest?code=510500&ma_period=60&buy_dev=10&sell_dev=10"
```

| 端点 | 说明 |
|------|------|
| `GET/POST /api/backtest` | 执行回测，返回偏离率序列、净值、成交明细与绩效指标 |
| `GET/POST /api/symbols` | 标的清单 |
| `POST /api/clearcache` | 清空行情缓存并重新拉取 |
| `POST /api/info` | 返回本机局域网访问地址 |
| `POST /api/qr` | 生成访问地址二维码（SVG） |
